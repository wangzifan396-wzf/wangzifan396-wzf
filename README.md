## 设计原则

- **零依赖 · 单文件** —— 每个 `index.html` 双击即开，可随身携带
- **本地优先** —— 无外部请求，断网可用，数据永不离机
- **隐私第一** —— 全部浏览器内计算，不传任何数据到服务器
- **统一设计系统** —— Linear 冷峻暗色，克制动效，系统字体栈
- **测试驱动** —— 纯函数单测 + jsdom 功能测试，全绿才发布
